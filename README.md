# Secret Menu XRAY Toggle

Client-side Secret Menu opened with '*' key. Includes an XRAY button that toggles an X-ray-like mode by hiding non-ore blocks via client chunk render filtering and restores normal rendering when disabled.

Generated by **ModForge AI**.

- Minecraft: `1.21.11`
- Loader: Fabric `0.18.4`
- Fabric API: `0.141.4+1.21.11`

## Build

```bash
./gradlew build
```
